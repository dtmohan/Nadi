# Fresh chart-reading parity and date-sensitivity protocol

Frozen before running this sample: use the four newly selected people and eleven dated events in `scripts/fixtures/reading-parity-fresh.json`. None may appear in any earlier structured fixture. The cases span India, Britain, Mexico and South Africa, film and politics; they are a convenience sample, not representative of the population. Birth clocks have different evidential quality, and Mandela's 14:54 is an earlier astrologer's rectification rather than a recorded time. Report this separately; it cannot validate time selection.

For each event, check the reported birth input and the stated local event clock/zone. Where a clock is missing use noon and label it assumed; where sources say approximately noon, keep that uncertainty. Compare (1) natal KP cusp and Parashari frames with the identical date-independent pieces of the chosen-date reading, (2) that reading with Validate, and (3) one Rectify midpoint per person with a recast of the exact same midpoint. Compare every registered KP event-output field and the complete Parashari evidence objects. A discrepancy is a failure, not a score to be tuned away.

For each actual event, separately evaluate six dates at −180, −120, −60, +60, +120 and +180 days with the same clock and zone. Record v1/v2/v3, KP event and transit scores, Aurora full-chain flags, and the Parashari conditional flags. Count how often each control shares the actual event's values. These fixed-offset dates are not verified non-events; this is a sensitivity check only, and matching a date is neither a prediction nor a birth-time accuracy measure. Evaluate prespecified alternate event clocks and the two listed Cameron and Mandela birth-clock alternatives; the Mandela alternatives are hypothetical afternoon samples, not documented observations. No rule tuning or candidate selection is allowed on these results.

Save compact raw results and a hash of the fixture, protocol, evaluator and rule implementation. Summarize all cases, counts, assumptions and failures, including any unavailable comparisons. Repeating the previous conditional-rule cases is a separate regression check and must not be counted as fresh evidence.
